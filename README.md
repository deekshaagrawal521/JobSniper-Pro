JobSniper Pro 🚀
JobSniper Pro is an AI-powered job application assistant web app designed to help freshers track, match, and apply for jobs. It provides enhanced resume support, job description matching, and cover letter generation, making job hunting easier and more efficient.

Features ✨
Resume Analysis: Upload your resume to get instant feedback on its effectiveness and suggestions for improvement.

Job Description Matching: Input a job description, and the app will compare it with your resume and highlight missing or mismatched skills.

Cover Letter Generation: Automatically generate a personalized cover letter based on the job description and your resume.

Job Tracker: Track your job applications, their statuses, and follow-up reminders.

Resume Builder: Create and customize resumes from scratch using an easy-to-use interface.

Tech Stack 🛠
Frontend: HTML, CSS, JavaScript, Next.js

Backend: Node.js, Express

Database: MongoDB

UI Framework: Tailwind CSS, shadcn/ui

APIs: Adzuna API for job search functionality

Other Tools: Recharts for data visualization, React for building interactive UI

Usage 🧑‍💼
Sign Up/Login: Create an account or log in to start using the features.

Upload Resume: Upload your resume to receive detailed feedback.

Match Job Descriptions: Enter a job description and compare it with your resume for personalized suggestions.

Generate Cover Letter: Based on the job description, automatically generate a cover letter.

Track Applications: Add job applications to track their status and receive follow-up reminders.

Build Your Resume: Use the built-in resume builder to create a professional resume.
